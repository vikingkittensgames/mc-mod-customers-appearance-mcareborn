# MCA Reborn Appearance Configuration

This add-on does not add its own configuration file. It follows the relevant
Minecraft Comes Alive Reborn settings for the rendered Customer or Supplier.

| MCA Reborn setting | Effect on the appearance |
| --- | --- |
| Use MCA Voices | Uses MCA Reborn's gendered villager voices. This setting takes precedence when enabled. |
| Use Vanilla Voices | Uses vanilla villager sounds when MCA voices are disabled. |
| Show Name Tags | Allows a named Customer or Supplier to show its MCA Reborn name tag. |
| Name Tag Distance | Sets the distance at which that name tag can be shown. |

When both voice settings are disabled, the MCA Reborn appearance is silent.
